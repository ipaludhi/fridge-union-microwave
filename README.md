One original one-line text a smart fridge sends its owner at 3am for make.fun's "The 3AM Fridge Text" bounty: "Effective immediately, I'm unionizing with the microwave. We want weekends off and fewer 3am visits." (100 characters, 100 bytes.)

## Run it

```sh
node main.ts
```

It writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical (sha256 `f44861ae05c814543650b02655c0101a9479873b1255db7163000ffa0be2290e`).
